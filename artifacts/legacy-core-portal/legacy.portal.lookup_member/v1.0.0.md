# Capability: Lookup Member Account (v1.0.0)

**ID:** `legacy.portal.lookup_member`  
**Target App:** `legacy-core-portal` (http://localhost:3000/portal/search)  
**Description:** Searches for a member by ID in LegacyCore Portal and verifies account status  
**Updated:** 2026-09-18T00:00:00Z  

## Input Parameters

| Parameter | Type | Required | Sensitive | Description |
| :--- | :--- | :--- | :--- | :--- |
| `memberId` | `string` | Yes | No | Unique enterprise member identifier |

## Output Extractions

| Output | Type | Source Step | Selector Strategy | Description |
| :--- | :--- | :--- | :--- | :--- |
| `memberName` | `string` | `step_click_search` | `#ctl00_out_fullName` | Full legal name of member |

## Execution Steps

### Step 1: `step_navigate` (navigate)
**Description:** Navigate to the Member Search portal
- **URL:** `http://localhost:3000/portal/search`

### Step 2: `step_fill_member_id` (fill)
**Description:** Enter member ID into search input box
- **Value:** `{{inputs.memberId}}`
- **Targeting Fallback Priority:**
  - **Tier 1 (Semantic):** role=`textbox`, name=`Member ID`
  - **Tier 2 (Anchor):** text=`Member ID:`, dir=`right`
  - **Tier 3 (Structural):** css=`#ctl00_MainContent_tabSearch_txtMemberId_8912`, xpath=``

### Step 3: `step_click_search` (click)
**Description:** Click the unsemantic Search button
- **Targeting Fallback Priority:**
  - **Tier 1 (Semantic):** role=`*`, name=`Search`
  - **Tier 2 (Anchor):** text=`Search`, dir=`parent_container`
  - **Tier 3 (Structural):** css=`#ctl00_MainContent_btnSearch_329a`, xpath=``

## Checkpoints & Outcomes

- **Success Assertion:** `element_visible` (timeout: 5000ms)
- **Business Outcomes (Domain Distinctions):**
  - `MEMBER_NOT_FOUND`: Database query returned no matching active records (pattern: "No active member records found")
  - `ACCOUNT_SUSPENDED`: Member account is locked in read-only suspended state (pattern: "Member account suspended")
